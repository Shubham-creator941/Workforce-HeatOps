# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone. Be respectful, constructive, and considerate. Unacceptable behavior includes harassment, discrimination, personal attacks, and publishing others’ private information.

Project maintainers may remove or reject contributions and participation that violate these expectations. Report concerns privately to the project maintainers. Enforcement decisions will prioritize community safety and fairness.
